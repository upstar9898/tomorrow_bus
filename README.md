# 🚍 내일의버스 (Tomorrow Bus)

> **앉아서 가는 출근길, 내일의버스로 준비하세요** 

서울시 광역버스의 **미래 시점 좌석 상태를 예측하는 AI 서비스**

---

## 📌 프로젝트 개요

출퇴근 시간대 광역버스는 반복적인 혼잡 패턴을 보입니다.

하지만 기존 서비스는
👉 **현재 시점의 좌석 정보만 제공**

즉,
👉 사용자가 실제로 탑승하는 **미래 시점의 좌석 상태는 알 수 없음**

이를 해결하기 위해
👉 **시간, 노선, 정류소 기반으로 좌석 상태를 예측하는 서비스**를 개발했습니다. 

---

## 🎯 서비스 기능

### 1. 개별 정류소 좌석 예측

* 특정 시간에 해당 정류소에서 탑승 시
* 좌석이 있을지 예측

### 2. 노선 전체 좌석 예측

* 버스 이동 경로를 따라
* 정류소별 좌석 상태를 시각적으로 제공

---

## 🔄 시스템 흐름

```
API 데이터 수집 → DB 저장 → 데이터 전처리 → EDA → 모델 학습 → 모델 통합 → 웹 서비스 제공
```

👉 전체 파이프라인 기반으로 데이터부터 서비스까지 구현

## 📡 데이터 수집

### 버스 데이터

* 서울시 버스 도착정보 API 활용
* 스케줄러 기반 주기적 수집

### 날씨 데이터

* 기상청 관측 데이터 활용

---

## 🧹 데이터 전처리

### 주요 처리 과정

* 잔여 좌석 변수 정제 (`reride_Num1`)
* 시간 파생 변수 생성

  * year, month, day, hour, minute
  * dayofweek, 공휴일 여부
* 만차 여부 라벨링

  * 0석 → 만차
  * 그 외 → 비만차

### 운행 단위 데이터 구성

* 동일 차량 기준 trip 분리
* 시간 간격 및 정류소 순서 기반 그룹화
* 도착 정보 신뢰도 기준 필터링

  * “곧 도착”, “0번째 전” 중심

👉 실제 운행 단위 데이터를 구성해 학습 데이터 품질 확보

## 🌦 날씨 데이터 처리

* **공간 매핑** (가장 가까운 관측소)
* 생성 변수

---

## 📊 데이터 분석 (EDA)

### 주요 가설 및 결과

#### 1. 혼잡은 시간대에 따라 발생

* 출근 시간 집중 (7~9시)
* 주말 혼잡 거의 없음

#### 2. 특정 정류소에 승객 집중

* `staOrd` (정류소 순서) 핵심 feature

#### 3. 만차는 특정 노선에 집중

* 일부 노선에서만 의미 있는 만차 발생

#### 4. 날씨 영향 존재

* 비 오는 날 혼잡 증가
* 기온 영향은 제한적

👉 시간 + 공간 + 패턴 + 날씨가 핵심 변수로 확인 

---

## 🧠 모델 설계

### 최종 구조 (Hybrid)

* **회귀 모델** → 잔여 좌석 수 예측
* **이진 분류 모델** → 만차 여부
* **다중 분류 모델** → 혼잡도 (여유 / 보통 / 혼잡 / 만차)

👉 3개 모델을 동시에 추론하여 결과 제공 

---

## ⚙️ 모델 선택

다양한 모델 비교 결과:

| 모델                | 특징           |
| ----------------- | ------------ |
| Linear Regression | 비선형 패턴 반영 불가 |
| MLP               | 성능 부족        |
| XGBoost           | 높은 성능        |
| CatBoost          | 불안정          |
| **LightGBM**      | 성능 + 속도 균형   |

👉 **LightGBM 최종 채택**
