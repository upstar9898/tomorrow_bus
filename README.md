
# 🚍 내일의버스 (Tomorrow Bus)

> 앉아서 가는 출근길, 내일의버스로 준비하세요

서울시 광역버스의 미래 시점 좌석 상태를 예측하는 AI 서비스

---

## 📌 프로젝트 개요

출퇴근 시간대 광역버스는 반복적인 혼잡 패턴을 보입니다.

하지만 기존 서비스는 현재 시점의 좌석 정보만 제공하며,  
사용자가 실제로 탑승하는 미래 시점의 좌석 상태는 알 수 없습니다.

이를 해결하기 위해 시간, 노선, 정류소 기반으로 좌석 상태를 예측하는 서비스를 개발했습니다.

---

## 🎯 서비스 기능

### 1. 개별 정류소 좌석 예측
- 특정 시간에 해당 정류소에서 탑승 시 좌석 여부 예측

### 2. 노선 전체 좌석 예측
- 버스 이동 경로를 따라 정류소별 좌석 상태 제공

## 📡 데이터 수집

### 버스 데이터
- 서울시 버스 도착정보 API 활용
- 스케줄러 기반 주기적 수집

### 날씨 데이터
- 기상청 관측 데이터 활용
- 정류소 기준 가장 가까운 관측소 매핑

---

## 🧹 데이터 전처리

- 잔여 좌석 변수 정제
- 시간 파생 변수 생성 (연, 월, 일, 시, 분, 요일)
- 공휴일 여부 생성
- 만차 여부 라벨링
  - 0석 → 만차
  - 1석 이상 → 비만차

### 운행 단위 데이터 구성
- 동일 차량 기준 trip 분리
- 시간 간격 및 정류소 순서 기반 그룹화
- 신뢰도 높은 도착 정보 기준 필터링

---

## 🌦 날씨 데이터 처리

- 시간 단위 매핑 (1시간 기준)
- 위치 기반 매핑 (가장 가까운 관측소)
- 생성 변수
  - 강수 여부
  - 기온

---

## 📊 데이터 분석 (EDA)

### 주요 결과

- 출근 시간대 혼잡 집중 (7~9시)
- 특정 정류소에 승객 집중
- 만차는 일부 노선에 집중
- 비 오는 날 혼잡 증가

---

## 🧠 모델 설계

### Hybrid 구조

- 회귀 모델 → 잔여 좌석 수 예측
- 이진 분류 모델 → 만차 여부
- 다중 분류 모델 → 혼잡도 (여유 / 보통 / 혼잡 / 만차)

---

## ⚙️ 모델 선택

- Linear Regression: 비선형 패턴 반영 한계
- MLP: 성능 부족
- XGBoost: 높은 성능
- CatBoost: 불안정
- LightGBM: 성능과 속도의 균형

→ LightGBM 최종 채택

---

## 📈 성능

- 회귀 MAE: 약 3.3
- 만차 분류 Accuracy: 약 97%
- 혼잡도 분류 Macro F1: 약 0.7
