원하는 노선과 승차 시간을 선택하면
특정 정류장만이 아니라
전체 노선의 예측 잔여좌석을 보여주는 페이지

현재 페이지는 개발 중입니다. 실제 서비스에서는 노선 전체 정류장에 대한 예측 결과를 지도 또는 리스트 형태로 시각화해, 어느 구간에서 좌석 여유가 있는지 한눈에 확인할 수 있게 됩니다.

서비스 개요

서비스2는 사용자가 노선 번호와 승차 시간을 입력하면, 해당 노선의 각 정류장별 예상 잔여좌석을 한 번에 보여주는 기능입니다. 단일 정류장 예측보다 넓은 시야를 제공해, 어느 구간에서 혼잡이 심한지, 어느 정류장에서 상대적으로 좌석 여유가 있는지를 비교할 수 있도록 설계합니다.

입력
노선 번호, 승차 시간
출력
전체 정류장별 잔여좌석 예측
표현 방식
지도, 리스트, 상태 배지

개발 상태

현재 페이지는 레이아웃 초안 단계입니다.
  • 노선 선택 UI 추가 예정
  • 지도 API 연동 예정
  • 정류장별 예측 결과 배지 표시 예정
  • 실제 예측 API 연결 예정
